# 1. Мета продукту
Програма, що нагадує користувачу про техогляд його автомобіля,  
буде відправляти йому повідомлення на пошту.  
Зручний інтерфейс для користувача,  
зміна різних параметрів та створення нових нагадувань повинна бути зручною для користувача.

---

# 2. Обсяг проєкту
- Створення веб-застосунку  
- Створення логіки застосунку  
- Інтеграція з базою даних  
- Впровадження нагадувань
